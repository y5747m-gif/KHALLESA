# خَلِّصها — KHALLESA

> **مش هنفكّرك بس… هنقولك تعمل إيه.**

**خَلِّصها** يحوّل أي مشكلة (مكتوبة، منطوقة، أو مصوَّرة) إلى **خطة تنفيذ حقيقية**: خطوات، مستندات، مصادر رسمية، عواقب التجاهل — ثم يتابعك حتى تنتهي.

```
مشكلة ← فهم ← خطة ← مصادر ← إجراءات ← متابعة ← إثبات الانتهاء
```

## 📲 ثبّت التطبيق على موبايلك

### 1) زر التثبيت جوه التطبيق (أسهل طريقة)
افتح **المزيد ⚙️ ← ثبّت التطبيق على موبايلك**:

- **أندرويد (Chrome / Edge):** اضغط **تثبيت التطبيق** — هيظهر على الشاشة الرئيسية في ثانية ويفتح كتطبيق (بدون شريط المتصفح).
- **iPhone / iPad (Safari):** التطبيق يعرض لك الخطوات: زر **المشاركة ↑** ← **إضافة إلى الشاشة الرئيسية** ← **إضافة**.
- كمان في **بانر** أعلى الصفحة الرئيسية تقدر تثبّت منه أو تضغط «لاحقًا» (ويرجع لك بعد أسبوعين).

> التطبيق **بيشتغل أوفلاين** بعد أول مرة (Service Worker) — وبياناتك كلها على جهازك.

### 2) تطبيق أندرويد المنفرد (APK)
ده مش «صفحة ويب مثبتة» — ده تطبيق كامل مبني بـ Capacitor وموقّع بمفتاح إصدار ثابت، يعني أي نسخة جديدة بتتثبّت فوق القديمة من غير ما تفقد بياناتك.

رابط ثابت دايمًا بآخر بناء:

```
https://github.com/y5747m-gif/KHALLESA/releases/download/latest-apk/khallesa.apk
```

1. حمّل الملف من الرابط (أو من زر **حمّل ملف APK** جوه التطبيق).
2. افتح الملف ← **تثبيت** ← لو ظهر تحذير «مصدر غير معروف» سمح بيه لمرة واحدة.
3. افتح **خَلِّصها** من درج التطبيقات — نفس المميزات بالظبط: خطط، OCR، تنبيهات، وثائق، عائلة، وخَلِّص AI — وكلها على جهازك.

الملفات المنشورة في [Releases](https://github.com/y5747m-gif/KHALLESA/releases):

| الملف | الوصف |
|---|---|
| `khallesa.apk` | التطبيق الموقّع — ده اللي تثبّته على موبايلك |
| `khallesa.aab` | Android App Bundle — للرفع على Google Play |
| `khallesa-debug.apk` | نسخة debug للتجربة السريعة |
| `khallesa.apk.sha256` | بصمة الملف للتأكد إنه سليم |

طرق تانية للتحميل:
- من **Actions** ← آخر تشغيل ناجح لـ **Build APK** ← Artifact باسم `khallesa-apk`.
- أي نسخة موسومة `v*` (مثل `v1.3.0`) تُرفع تلقائيًا لصفحة **Releases**.

## 🛠️ التشغيل للتطوير

```bash
npm install
npm run dev      # http://localhost:5173
npm run assets   # ينسخ محرك OCR + نماذج اللغات + الخطوط لـ public/ (بيشتغل تلقائيًا مع build)
npm run build    # بناء نسخة الإنتاج في dist/
npm run preview  # يجرب نسخة الإنتاج (مع زر التثبيت والـ Service Worker)
npm run icons    # يولّد أيقونات PWA في public/icons
npm run keystore # يولّد مفتاح توقيع الإصدار (مرة واحدة)
npm run lint
```

## 🤖 بناء التطبيق محليًا

```bash
npm run build
npx cap sync android
npx cap open android   # ثم Run من Android Studio
```

أو بأمر واحد (بيبني الـ debug APK في `android/app/build/outputs/apk/debug/`):

```bash
npm run apk
```

وللإصدار الموقّع (APK + AAB في `android/app/build/outputs/`):

```bash
npm run keystore        # مرة واحدة — يولّد android/keystore/release.p12 + keystore.properties
cd android && ./gradlew assembleRelease bundleRelease
```

يتطلب: Android Studio + JDK 21. في CI (GitHub Actions) كل ده تلقائي مع كل push.

## 🧠 ملاحظات تقنية

- **أولوية الخصوصية:** كل البيانات في `localStorage` على الجهاز — لا يوجد سيرفر في V1.
- **التثبيت كتطبيق:** `public/manifest.webmanifest` + أيقونات PNG (192/512 + maskable) + `public/sw.js` (تخزين أوفلاين للشل، الخطوط، ومحرك OCR).
- **زر التثبيت:** `src/lib/install.ts` (يمسك `beforeinstallprompt`، يكتشف iOS والوضع المثبّت) + `src/components/InstallApp.tsx` (كارت في «المزيد» + بانر في الرئيسية).
- **الغلاف الأصلي** (`src/lib/native.ts`): شريط الحالة، السبلاش، زر الرجوع (شاشة مفتوحة ← تبويب ← خروج)، الروابط الخارجية في متصفح النظام، ومعلومات التطبيق — وكلها no-op على الويب فالكود واحد للمنصتين.
- **جوه الـ APK:** نفس الكود بالظبط — الكارت بيكتشف أنه جوه التطبيق (Capacitor) ويعرض «عن التطبيق» (الإصدار، رقم البناء، معرّف الحزمة) بدل زر التثبيت.
- **OCR بدون شبكة:** `scripts/copy-native-assets.mjs` بينسخ `worker.min.js` ونواة WASM من `tesseract.js-core` ونماذج `ara`/`eng` من `@tesseract.js-data` إلى `public/` — و`src/lib/ocr.ts` بيشاور عليهم محليًا بدل CDN الخاص بـ jsdelivr. add `--full` عشان تشحن نسخ SIMD كمان (تعرّف أسرع، +7.4 ميجا).
- **التوقيع:** مفتاح التوزيع في `android/keystore/release.p12` (committed عمدًا عشان كل البناءات تتوقّع بنفس المفتاح). لو هترفع على Google Play: حط مفتاحك في Secrets باسم `ANDROID_KEYSTORE_BASE64` + `ANDROID_KEYSTORE_PASSWORD` + `ANDROID_KEY_ALIAS` + `ANDROID_KEY_PASSWORD` والـ workflow هيستخدمها الأول.
- **المحرك المحلي** (`src/lib/engine.ts`) يفهم العربية المصرية: تواريخ ("الشهر الجاي"، "15 أكتوبر")، مبالغ، متاجر، وفئات (مرور، سفر، فواتير، ضمان...).
- **تحسين AI اختياري:** من "المزيد ← تحسين الذكاء الاصطناعي" ضف مفتاح API متوافق مع OpenAI — يُحفظ على جهازك فقط.
- **المصادر الرسمية** (`src/lib/sources.ts`): مصر الرقمية، خدمات المرور، نيابة المرور، حماية المستهلك وغيرها — وأي معلومة رسوم/مواعيد بدون مصدر تأخذ شارة "تحتاج تحقق".

## 🌍 English

**KHALLESA** turns any problem (typed, spoken, or snapped) into a real action plan: steps, documents, official sources, consequences of ignoring — then follows up until done.

- Full bilingual UI: Arabic (RTL) + English (LTR) — pick at onboarding or from More → Language
- The engine understands both Egyptian Arabic and English input and builds plans in your language
