# خَلِّصها — KHALLESA

> **مش هنفكّرك بس… هنقولك تعمل إيه.**

**خَلِّصها** يحوّل أي مشكلة (مكتوبة، منطوقة، أو مصوَّرة) إلى **خطة تنفيذ حقيقية**: خطوات، مستندات، مصادر رسمية، عواقب التجاهل — ثم يتابعك حتى تنتهي.

```
مشكلة ← فهم ← خطة ← مصادر ← إجراءات ← متابعة ← إثبات الانتهاء
```

## ✨ نسخة V1 — خَلِّصها مصر 🇪🇬

| الميزة | الوصف |
|---|---|
| 🏠 Command Center | "إيه اللي عايز تخلّصه؟" + عدّادات (محتاجك / قرّب / منتظر / خلصته) |
| 🎤📷 إدخال مرن | كتابة، صوت (عربي)، أو تصوير ورقة |
| 🔍 OCR | قراءة الفواتير والخطابات والإيصالات (عربي + إنجليزي) على الجهاز |
| 🧠 محرك الخطط | يفهم المشكلة ويبني خطة تنفيذ مصرية بخطوات ومستندات ومصادر |
| 🧠 ماذا أفعل الآن؟ | ترتيب أولوياتك حسب الموعد والعواقب — مش حسب وقت الإنشاء |
| ⚠️ لو تجاهلتها | كل مسار يوضح عواقب التأخير |
| 🛡️ شارات الثقة | مصدر رسمي / موثوق / يحتاج تحقق / لا تستخدم دون تحقق |
| 🗺️ مساراتي | سيارة، منزل، عمل، سفر، فلوس، أوراق، عائلة |
| 🗂️ الوثائق | خزنة صور وملاحظات على جهازك |
| 👨‍👩‍👧‍👦 العائلة | مسارات تخص أفراد الأسرة مع تعيين مسؤول |

| 📄 ملف المطالبة | للضمان والإرجاع — مشاركة/تحميل |
| 🔔 المتابعة | تنبيهات قبل المواعيد (ويب + تنبيهات نظام داخل التطبيق) |
| 🌙 الوضع الليلي | فاتح / غامق / تلقائي |

## 📱 تحميل التطبيق (APK)

1. افتح صفحة **Actions** في الريبو ← اختر آخر تشغيل ناجح لـ **Build APK**.
2. حمّل ملف `khallesa-debug-apk` من قسم **Artifacts** (بداخله `app-debug.apk`).
3. ثبّته على موبايلك الأندرويد وافتحه — كل بياناتك محفوظة على جهازك فقط.
4. أي نسخة موسومة `v*` (مثل `v1.0.0`) تُرفع تلقائيًا لصفحة **Releases**.

## 🛠️ التشغيل للتطوير

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # بناء نسخة الإنتاج في dist/
```

## 🤖 بناء APK محليًا

```bash
npm run build
npx cap sync android
npx cap open android   # ثم Run من Android Studio
```

يتطلب: Android Studio + JDK 17.

## 🧠 ملاحظات تقنية

- **أولوية الخصوصية:** كل البيانات في `localStorage` على الجهاز — لا يوجد سيرفر في V1.
- **المحرك المحلي** (`src/lib/engine.ts`) يفهم العربية المصرية: تواريخ ("الشهر الجاي"، "15 أكتوبر")، مبالغ، متاجر، وفئات (مرور، سفر، فواتير، ضمان...).
- **تحسين AI اختياري:** من "المزيد ← تحسين الذكاء الاصطناعي" ضف مفتاح API متوافق مع OpenAI — يُحفظ على جهازك فقط.
- **المصادر الرسمية** (`src/lib/sources.ts`): مصر الرقمية، خدمات المرور، نيابة المرور، حماية المستهلك وغيرها — وأي معلومة رسوم/مواعيد بدون مصدر تأخذ شارة "تحتاج تحقق".
