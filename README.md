# خَلِّصها — KHALLESA

> **مش هنفكّرك بس… هنقولك تعمل إيه.**

**خَلِّصها** يحوّل أي مشكلة (مكتوبة، منطوقة، أو مصوَّرة) إلى **خطة تنفيذ حقيقية**: خطوات، مستندات، مصادر رسمية، عواقب التجاهل — ثم يتابعك حتى تنتهي.

```
مشكلة ← فهم ← خطة ← مصادر ← إجراءات ← متابعة ← إثبات الانتهاء
```

## 📲 ثبّت التطبيق على موبايلك

### 1) زر التثبيت جوه التطبيق (أسهل طريقة)
افتح **المزيد ⚙️ ← ثبّت التطبيق على موبايلك**:

- **أندرويد (Chrome / Edge):** اضغط **تثبيت التطبيق** — هيظهر على الشاشة الرئيسية في ثانية ويفتح كتطبيق (بدون شريط المتصفح).
- **iPhone / iPad (Safari):** التطبيق يعرض لك الخطوات: زر **المشاركة ↑** ← **إضافة إلى الشاشة الرئيسية** ← **إضافة**.
- كمان في **بانر** أعلى الصفحة الرئيسية تقدر تثبّت منه أو تضغط «لاحقًا» (ويرجع لك بعد أسبوعين).

> التطبيق **بيشتغل أوفلاين** بعد أول مرة (Service Worker) — وبياناتك كلها على جهازك.

### 2) تحميل APK للأندرويد (نفس المميزات)
رابط ثابت دايمًا بآخر بناء:

```
https://github.com/y5747m-gif/KHALLESA/releases/download/latest-apk/khallesa.apk
```

1. حمّل الملف من الرابط (أو من زر **حمّل ملف APK** جوه التطبيق).
2. افتح الملف ← **تثبيت** ← لو ظهر تحذير «مصدر غير معروف» سمح بيه لمرة واحدة.
3. افتح **خَلِّصها** من درج التطبيقات — نفس المميزات بالظبط: خطط، OCR، تنبيهات، وثائق، عائلة، وخَلِّص AI — وكلها على جهازك.

طرق تانية للتحميل:
- من **Actions** ← آخر تشغيل ناجح لـ **Build APK** ← Artifact باسم `khallesa-apk`.
- أي نسخة موسومة `v*` (مثل `v1.2.0`) تُرفع تلقائيًا لصفحة **Releases**.

## 🛠️ التشغيل للتطوير

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # بناء نسخة الإنتاج في dist/
npm run preview  # يجرب نسخة الإنتاج (مع زر التثبيت والـ Service Worker)
npm run icons    # يولّد أيقونات PWA في public/icons
npm run lint
```

## 🤖 بناء APK محليًا

```bash
npm run build
npx cap sync android
npx cap open android   # ثم Run من Android Studio
```

أو بأمر واحد (بيبني الـ debug APK في `android/app/build/outputs/apk/debug/`):

```bash
npm run apk
```

يتطلب: Android Studio + JDK 21.

## 🧠 ملاحظات تقنية

- **أولوية الخصوصية:** كل البيانات في `localStorage` على الجهاز — لا يوجد سيرفر في V1.
- **التثبيت كتطبيق:** `public/manifest.webmanifest` + أيقونات PNG (192/512 + maskable) + `public/sw.js` (تخزين أوفلاين للشل، الخطوط، ومحرك OCR).
- **زر التثبيت:** `src/lib/install.ts` (يمسك `beforeinstallprompt`، يكتشف iOS والوضع المثبّت) + `src/components/InstallApp.tsx` (كارت في «المزيد» + بانر في الرئيسية).
- **جوه الـ APK:** نفس الكود بالظبط — الكارت بيكتشف أنه جوه التطبيق (Capacitor) ويقولك «إنت جوه تطبيق خَلِّصها ✅» بدل زر التثبيت.
- **المحرك المحلي** (`src/lib/engine.ts`) يفهم العربية المصرية: تواريخ ("الشهر الجاي"، "15 أكتوبر")، مبالغ، متاجر، وفئات (مرور، سفر، فواتير، ضمان...).
- **تحسين AI اختياري:** من "المزيد ← تحسين الذكاء الاصطناعي" ضف مفتاح API متوافق مع OpenAI — يُحفظ على جهازك فقط.
- **المصادر الرسمية** (`src/lib/sources.ts`): مصر الرقمية، خدمات المرور، نيابة المرور، حماية المستهلك وغيرها — وأي معلومة رسوم/مواعيد بدون مصدر تأخذ شارة "تحتاج تحقق".
